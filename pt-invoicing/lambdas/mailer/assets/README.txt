Optional branding for the invoice PDF. Drop files here, then run `cdk deploy`.

logo.png            Your logo. In the default "band" style it sits on your primary colour,
                    so use a light/white or transparent-background version.
                    If your logo is dark, set "pdf_style": "plain" under "brand" in config.json.
fonts/regular.ttf   Optional brand font (regular weight)
fonts/bold.ttf      Optional brand font (bold weight). Both fonts must be present to be used.
